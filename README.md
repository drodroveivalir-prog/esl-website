# Electro Security Limited Website

Professional responsive website for Electro Security Limited (ESL), Fiji.

## Files
- `index.html` - main website
- `style.css` - responsive styling
- `script.js` - mobile navigation and enquiry form
- `assets/esl-logo.png` - ESL logo

## Contact form
The form is prepared for Formspree. Replace `YOUR_FORM_ID` in `index.html` with the Formspree endpoint/form ID for ESL before publishing.

## GitHub Pages
This is a static website and can be hosted with GitHub Pages.
